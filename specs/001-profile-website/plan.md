## Summary

Build a complete, single-file professional profile website in HTML/CSS/JS (no frameworks, no external dependencies except Google Fonts and optionally GSAP via CDN). The site must include a hero section with typewriter effect, full navigation, about section with stats, skills gallery, projects portfolio, resume timeline, contact form, and custom cursor experience. All animations must be smooth and high-quality using IntersectionObserver and GSAP where available.

## Technical Context

**Language/Version**: HTML5, CSS3, Vanilla JavaScript (ES6+)  
**Primary Dependencies**: Google Fonts (Syne, DM Sans, JetBrains Mono), GSAP via CDN (with CSS fallback)  
**Storage**: N/A (client-side only, no backend)  
**Testing**: Manual browser testing, accessibility audit, Lighthouse  
**Target Platform**: Modern web browsers (Chrome, Firefox, Safari, Edge)
**Project Type**: Single-file web application (static HTML with embedded CSS/JS)  
**Performance Goals**: 60 FPS animations, <2s load time on 3G, <100ms interaction response  
**Constraints**: Single HTML file, no build tools, no npm, no external CSS/JS files (except CDN fonts/GSAP)  
**Scale/Scope**: Single-page site with ~200-300 lines of CSS, ~400-500 lines of JS
